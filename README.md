# Crum Blog - AI 기반 자동화 블로그

## 프로젝트 개요
AI 기반 자동 콘텐츠 생성과 트렌드 분석을 통해 최신 이슈와 정보를 제공하는 자동화 블로그 미디어 사이트

## 기술 스택
- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: Strapi 5 (Headless CMS)
- **Database**: PostgreSQL (Supabase)
- **Automation**: Node.js, OpenAI API, Google Trends API
- **Hosting**: Vercel (Frontend), Railway (Backend)
- **Monetization**: Google AdSense, Coupang Partners

## 개발 단계
- **Phase 1**: 기본 인프라 구축 (Week 1)
- **Phase 2**: 자동화 시스템 (Week 2-3)
- **Phase 3**: SEO 최적화 (Week 4)
- **Phase 4**: 수익화 시스템 (Week 5-6)
- **Phase 5**: 모니터링 및 개선 (Week 7+)
